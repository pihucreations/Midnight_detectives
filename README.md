# 🕵️ Midnight Detectives 🌙

> **Solve the clues. Crack the riddles. Follow the evidence. Uncover the mystery.**

**Midnight Detectives** is an interactive detective game where the player becomes the detective and works through mysterious cases filled with riddles, codes, clues, suspects, and unexpected twists.

Instead of simply reading a story, **you have to solve it.** 🔎

---

## 🎮 What is Midnight Detectives?

Midnight Detectives is a browser-based mystery game built with **HTML, CSS and JavaScript**.

Each case begins with something strange happening.

Maybe something disappears.

Maybe someone is lying.

Maybe an ordinary clue isn't quite as ordinary as it looks...

The player investigates by:

- 🧩 Solving riddles
- 🔐 Cracking secret codes
- 🔎 Examining clues
- 🎒 Collecting evidence
- 👀 Spotting suspicious details
- 🧠 Solving logic puzzles
- 🗣️ Investigating suspects
- 💡 Asking for hints when completely stuck
- ❤️ Trying to solve the case before running out of lives

Correct answers reveal new parts of the story and move the investigation forward.

## 🧠 The Idea

I wanted to create a detective game where solving the mystery actually requires **thinking**.

The goal isn't to just click through a story.

I want players to have moments where they stop and think:

> *"Wait... what does that clue mean?"*

or

> *"I KNOW THE ANSWER!"*

Some puzzles might take seconds.

Others might require combining several clues collected earlier in the investigation.

And sometimes...

**the obvious answer might be completely wrong.** 👀

---

## 🚧 Current Status

**Midnight Detectives is a work in progress.**

Right now, the game is personalized around me and includes characters, jokes and references created while I experiment with how the game should work.

That's intentional for now.

I'm using this version to figure out:

- what kinds of puzzles are the most fun
- how difficult the riddles should be
- how investigations should work
- how clues should connect together
- how the story should progress
- what makes solving a case feel satisfying

Eventually, I want to make the game easier for **anyone** to understand and play.
